# Official Rules Alignment

This project targets Problem Statement 1: Intelligent Workflow Automation Agent.

It demonstrates:

- enterprise data understanding across pricing, usage, invoices, exceptions, and approval documents;
- multi-step orchestration through CoCo CLI skills;
- deterministic anomaly detection;
- contextual evidence validation through Cortex Search;
- auditable finance review case creation;
- human-in-the-loop safety boundaries.

The prototype uses Python, Snowflake SQL, Cortex Search, Agent Skills, CoCo CLI prompt files, and Streamlit.
